# Переход на Postgres — что делать тебе

## ШАГ 1 (сейчас)

Код уже переведён на **переходную** версию: сайт по-прежнему на SQLite, добавлен экспорт/импорт. Сборка на Render без seed — данные не трогаются.

### 1.1 Закоммить и запушить в GitHub

В терминале из папки проекта:

```bash
git add -A
git commit -m "Transition: SQLite + export/import, no seed on deploy"
git push
```

### 1.2 Дождаться деплоя на Render

Зайди в панель Render → свой сервис taskpulse. Дождись, пока сборка закончится и статус станет зелёным (Deploy live).

### 1.3 Скачать бэкап

В терминале (из любой папки, куда хочешь сохранить файл):

```bash
curl -H "x-admin-key: admin" "https://taskpulse-1nqc.onrender.com/api/admin/export" -o taskpulse-backup.json
```

Проверь: открой `taskpulse-backup.json` — внутри должен быть JSON с полями `people`, `directions`, `tasks` и т.д., а не `{"error":"Not found"}`.
