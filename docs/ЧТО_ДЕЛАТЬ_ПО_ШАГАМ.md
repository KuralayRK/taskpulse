# Деплой на Postgres — данные при обновлениях не стираются

Код переведён на **PostgreSQL**. На проде при каждом деплое выполняется только `prisma migrate deploy` (без seed и без db push) — данные сохраняются.

## Что сделать один раз

### 1. Создать PostgreSQL в Render

- **Dashboard** → **New** → **PostgreSQL**
- Создай базу, скопируй **Internal Database URL** (формат `postgresql://user:pass@host/db?sslmode=require`)

### 2. Подключить БД к сервису taskpulse

- Открой свой **Web Service** (taskpulse) → **Environment**
- **Add Environment Variable**
  - **Key:** `DATABASE_URL`
  - **Value:** вставь скопированный URL

Сохрани. Без этой переменной сборка упадёт (Prisma ожидает Postgres).

### 3. Закоммитить и задеплоить

В терминале из папки проекта:

```bash
git add -A
git commit -m "PostgreSQL: migrate deploy only, data preserved on deploy"
git push
```

Дождись успешного деплоя. После этого сайт работает на Postgres, при следующих пушах данные не трогаются.
